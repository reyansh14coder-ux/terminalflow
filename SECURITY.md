# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within TerminalFlow, please send an email to your.email@example.com. All security vulnerabilities will be promptly addressed.

## Security Measures

### Authentication
- API keys are stored in environment variables
- No hardcoded credentials
- Secure credential storage options available

### Data Privacy
- No telemetry data collected by default
- AI features use encrypted connections
- Local-first architecture

### Code Security
- Regular dependency audits
- Signed releases
- Reproducible builds

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Security Updates

Security updates are released as soon as possible after a vulnerability is discovered. Watch the repository for updates.

## Best Practices

1. Keep TerminalFlow updated
2. Use a virtual environment when testing
3. Never share API keys
4. Report vulnerabilities responsibly

Thank you for helping keep TerminalFlow secure!
