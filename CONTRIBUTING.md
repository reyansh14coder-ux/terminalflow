# Contributing to TerminalFlow

Thank you for your interest in contributing to TerminalFlow! 🚀

## 🌟 Why Contribute?

- 🎯 **Make an impact** - Help thousands of developers
- 🧠 **Learn** - Work with experienced Rust developers
- 🏆 **Get recognized** - Your name in the contributors list
- 💰 **Potential rewards** - Top contributors may receive swag

## 🚀 Getting Started

### 1. Fork & Clone

```bash
# Fork on GitHub, then:
git clone https://github.com/reyansh14coder-ux/terminalflow.git
cd terminalflow
```

### 2. Set Up Development

```bash
# Install Rust (if not installed)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Install dependencies
cargo build

# Run tests
cargo test
```

### 3. Create a Branch

```bash
git checkout -b feature/amazing-feature
```

## 📝 Development Guidelines

### Code Style

- Follow Rust conventions (`rustfmt`)
- Add tests for new features
- Update documentation
- Keep commits clean

### Commit Messages

Use [Conventional Commits](https://www.conventionalcommits.org/):

```
feat: add new AI feature
fix: resolve timeout issue
docs: update README
style: format code
refactor: improve performance
test: add unit tests
chore: update dependencies
```

### Pull Request Process

1. Update README.md with details of changes
2. Update the CHANGELOG.md
3. Ensure all tests pass
4. Request review from maintainers

## 🎯 Good First Issues

Look for issues labeled:
- `good first issue`
- `help wanted`
- `documentation`
